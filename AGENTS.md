# KhmerLens development guidance

Keep this a small weekend MVP in Python and Streamlit.
The current app is a scaffold. Implement features incrementally.
Never present preview text, dictionary matching, or placeholders as model output.
Keep unknown words and missing definitions explicit.
Verify Khmer library compatibility and data licenses before integration.
Do not commit credentials, virtual environments, or private user input.
Update README status when features are actually implemented.
